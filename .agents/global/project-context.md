# Project Context

This repository is a production-grade monorepo for the Assignment & Submission Management System.

Repository structure:
- frontend/
- backend/
- docs/

The documents inside `/docs` are the single source of truth:
- Project Assumptions
- System Design
- Database Design
- API Design

Never generate code that contradicts these documents.

When working in `frontend/`, follow:
- Global rules
- Frontend-specific rules

When working in `backend/`, follow:
- Global rules
- Backend-specific rules

Prefer production-ready, scalable, and maintainable solutions over shortcuts.
