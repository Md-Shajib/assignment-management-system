# UI Guidelines

Design System:

- Typography: Inter
- Spacing: 8px grid
- Border Radius: 12–16px
- Icons: Lucide
- Style: Clean, modern, premium SaaS

Rules:

- Never hardcode colors, spacing, sizing etc. Use Tailwind theme.
- Maintain consistent spacing and alignment.
- Reuse UI components whenever possible.
- Use semantic colors for status and feedback.
- Prioritize accessibility and readability.
- Keep interfaces simple and uncluttered.
- Avoid unnecessary animations and visual noise.
